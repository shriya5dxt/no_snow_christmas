# no_snow_christmas

A static website with warm-weather Christmas itinerary ideas — beaches, cities and festive traditions around the world, without the snow.

## Features
- 12 itineraries (Goa, Kerala, Cape Town, Sydney, Tulum, Rio, Tenerife, Phuket/Krabi, Maui, Dubai, Bali, Puerto Rico)
- Filter by vibe, region, budget and trip length, plus free-text search
- Day-by-day plans, local Christmas traditions and tips
- "Surprise me" random pick and a shortlist saved in your browser

## Run locally
No build step — just open `index.html` in a browser.

## Add a destination
Add an entry to the `ITINERARIES` array in `app.js`.
